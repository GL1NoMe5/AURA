# Ресурсы для визуала AURA

Локальные навыки и закреплённые исходники, использованные при разработке AURA. Приложение и подготовленные ассеты портрета уже существуют; инструкции запуска находятся в корневом README. Эти ресурсы нужны для разработки и повторной подготовки ассетов, а не для запуска готового приложения.

## Установленные skills

Общая папка `.agents/skills` доступна Codex и Muse Code:

- `frontend-design` — композиция, типографика и визуальная проверка; Anthropic, Apache-2.0.
- `threejs-shaders`, `threejs-postprocessing`, `threejs-performance`, `threejs-animation` — CloudAI-X, MIT.
- `threejs-particles` — системы частиц, буферы и нагрузка; cesartevisual, MIT.

У Wonder также есть включённый плагин Three.js. Не нужно читать одновременно одинаковые материалы из плагина и локальных skills. Наличие навыков не меняет разделение работы: визуал реализует Codex, Wonder получает другие задачи.

## Исходники и модель

- `references/threejs` — официальные примеры облака точек из глубины, пользовательских атрибутов частиц и Unreal Bloom, а также лицензия и package.json исходной версии. Это фрагмент upstream-репозитория для изучения, а не самостоятельное запускаемое приложение; ресурсы демонстраций и сборка Three.js сюда не включены.
- `vendor/psrdnoise` — исходники GLSL-шума и документация, MIT. Для AURA основной ориентир — `src/psrdnoise3.glsl`.
- `vendor/depth-anything-v2` — исходный код Depth Anything V2. Не исполнять автоматически скрипты из скачанного репозитория.
- `models/depth-anything-v2-small` — веса Small (`vits`, около 99 MB), карточка модели, Apache-2.0. SHA-256 сверяется с опубликованными LFS-метаданными Hugging Face. Другие размеры модели не скачаны.
- `licenses` — лицензии источников навыков; исходные репозитории сохраняют свои лицензии.
- `sources.json` — точные Git/Hugging Face revisions, местоположения и контрольные суммы скачанных файлов.

Веса модели исключены из Git. Для воспроизведения загрузки использовать model repository и revision из `sources.json`, затем сверить размер и SHA-256. PyTorch/CUDA и остальные зависимости подбирать отдельно на этапе подготовки портрета.

## Как использовать

Codex отвечает за UI, лицо, шейдеры, анимацию и визуальную приёмку. Сначала утверждается визуальный эталон и проверяется сцена без API-вызовов; затем она связывается с реальными событиями приложения. Depth-портрет — рельеф видимой поверхности с небольшими поворотами, а не готовая полная 3D-голова или лицевая анимация.

Для текущего набора не установлены Impeccable и UI UX Pro Max: они были рассмотрены, но не выбраны. Платные сервисы и внешние дизайн-движки не подключены.
