# Vision capability fixture

`vision-probe.png` is a 256x256 RGB image: blue (#247AC4) top half, amber (#E7AF50) bottom half. Generated by Codex using the PNG specification and Python standard library. It is a synthetic API test input, not a product asset or telemetry chart.

The capability probe asks the model to identify the colors in their top/bottom order. A passing answer establishes basic image input support only; actual graph interpretation is tested with measured telemetry during the swarm stage.
